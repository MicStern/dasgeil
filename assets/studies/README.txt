Platz für echte Bildschirmaufnahmen/Mockups der drei Projekt-Platzhalter in
der Sektion "Ausgewählte Arbeiten" (#arbeiten), sobald vorhanden.

Aktuell werden dort ausschließlich CSS-gezeichnete, abstrakte
Designartefakte verwendet (Wireframe-Stacks, Flow-Diagramme,
Typografie-/Farbstudien - siehe script.js, Abschnitt 6 "Gemeinsame
abstrakte Vorschau-Bausteine"), damit keine erfundenen Projektbilder
suggeriert werden.

Sobald reale Bilder hier abgelegt werden, in content.js beim jeweiligen
Projekt das "images"-Array befüllen und die zugehörige Renderfunktion in
script.js (renderProjectFullWidth / renderProjectSplit / renderProjectIdentity)
so erweitern, dass sie ein <img> statt des CSS-Artefakts ausgibt.
